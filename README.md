# Ahnaf Hasan — Portfolio

My personal portfolio site, showcasing projects, skills, and a way to get in touch. Built from scratch with plain HTML, CSS, and JavaScript — no frameworks.

**Live site:** https://ahnafhasan-portfolio.netlify.app

## Tech Stack
HTML, CSS, JavaScript, EmailJS (contact form)

## Features
- Fully custom design and layout (no templates)
- Responsive across desktop and mobile
- Scroll-based reveal animations
- Custom terminal-style section transitions
- Working contact form (EmailJS) with live send-status feedback
- Project showcase linking out to live demos and GitHub repos

## Setup

This is a static site with no build step.

1. Clone this repo
2. Open `index.html` directly in a browser, or use a Live Server extension for local development
3. To use the contact form locally, you'll need your own EmailJS public key, service ID, and template ID — see `script.js` for where these go
